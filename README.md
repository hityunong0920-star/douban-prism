# DoubanLens · 豆瓣棱镜

> **豆瓣书影音游品味实验室（自娱自乐）** —— 无需后端、数据零上传、亮/暗双主题，支持 GitHub Pages / Vercel 零成本部署。

把你在豆瓣积累多年的**电影、读书、游戏、音乐**记录拖进浏览器，立刻生成**文化热力图、品味演进时间线、5★ vs 1–2★ 红黑长图卡片、积灰愿望单扭蛋机**，还能拖进好友记录来一场**口味碰撞**，两个人一起玩，独乐乐不如众乐乐。

## 功能总览（纯本地 vs AI 辅助）

DoubanLens 采用「本地统计 + 可选 AI 总结」的结构。不配置任何 API Key 也能完整使用所有统计、图表、随机抽取、双人对比与图片导出功能，所有计算都在浏览器本地完成。

| 模块 | 本地功能（无需 API Key） | 接入 AI 后的补充内容 |
| :--- | :--- | :--- |
| **1. 文化摄入热力图** | 按年份或最近 365 天展示标记密度（GitHub 热力图风格），支持按影/书/游/音筛选；统计最长连续记录、单日记录峰值与月度摄入节奏；点击任意日期可查看当天记录与短评 | — |
| **2. 品味演进时间线** | 按年份汇总标记数量、均分、品类占比、当年 5★ 精选与短评摘录，支持按时间正序或倒序查看 | 生成《品味演进编年史》：按年份梳理阅读、观影与听歌重心的迁徙脉络，概括各阶段标题与转向 |
| **3. 红黑榜与审美底线** | 将 5★ 偏爱红榜与 1–2★ 差评与雷区分栏对照，支持按品类筛选及仅看含短评条目；支持导出 2x PNG 长图（随亮/暗主题变化） | 结合高分偏好与低分评价，梳理品味画像、核心审美暗线、主要雷区与低分短评风格，并写入导出卡片 |
| **4. 愿望单随机抽取** | 从 `想看 / 想读 / 想玩`（可选包含 `在看 / 在读 / 在玩`）中随机抽取 1 项或 3 项，支持按品类与收藏时长（1 年以上 / 2 年以上 / 近半年）筛选 | 输入当前可用时间或想看的方向，从愿望单中筛选 3 项并给出简短理由 |
| **5. 双人口味对比** | 导入另一位用户的记录，按豆瓣条目 ID 匹配：计算评分相近度，列出共同高分条目、分差 ≥ 2★ 的分歧条目（并排对比双方短评）、各自的 5★ 推荐以及共同愿望单，支持导出对比图 | 概括两人的口味异同，并基于交集给出适合共同观看或阅读的建议 |

## 快速上手

### 第一步：本地启动

需要 **Node.js >= 18**（推荐 Node 20 / 22）：

```bash
git clone https://github.com/hityunong0920-star/douban-lens.git
cd douban-lens
npm install
npm run dev
```

启动后在浏览器访问终端输出的地址（默认 `http://localhost:5173/`）。

### 第二步：试用或导入数据

- **先看示例**：在首页点击「使用内置示例数据」，进入「品味碰撞」页后也可加载示例好友数据进行对比测试。
- **导入个人数据**：按下一节导出 CSV / Excel / JSON 文件，拖入首页上传区即可。

### 第三步：切换明暗主题

点击右上角图标可切换亮色与暗色两套配色，导出的长图会自动沿用当前主题：
- **亮色**：纸张质感 + 豆瓣绿 + 衬线标题
- **暗色**：深色背景 + 低饱和度点缀色

## 如何导出你的豆瓣数据（3 种方式）

豆瓣对传统服务端爬虫有严格的反爬与 IP 封禁策略，因此 **DoubanLens 刻意将“数据采集”与“分析展示”彻底解耦**，不内置易失效的爬虫，而是兼容多种采集来源：

### 方式 A（推荐）：用 AI Agent 浏览器辅助导出

如果你在使用具备浏览器操作能力的 AI 编程工具（如 **Antigravity、Claude Code、Codex** 等），可以让 Agent 直接操作你已登录的真实浏览器，以温和的人类浏览节奏读取 DOM 并导出标准 CSV：

1. 直接将本仓库根目录的 [SKILL.md](./SKILL.md) 提供给你的 Agent；
2. 或者直接复制下方指令发给 Agent：

```text
请帮我导出我的豆瓣个人书影音游完整记录（包含电影、读书、游戏、音乐的 看过/在看/想看、读过/在读/想读、玩过/在玩/想玩、听过/想听），保存为 UTF-8 BOM 编码的 CSV 文件（文件名：豆瓣记录_我的昵称.csv）。

要求：
1. 在浏览器打开 https://www.douban.com/，若未登录则暂停等我手动扫码登录；
2. 在已登录会话中以每页 1~2 秒的温和节奏分页读取 DOM 提取记录，遇验证码暂停由我手动完成；
3. 严格使用以下 8 列标准表头：
分类,状态,标题,评分,标记日期,标签,短评,链接
```

> **提示**：如果想和朋友玩「双人口味碰撞」，只要对方豆瓣主页公开，也可以让 Agent 用同样的方式抓取对方公开的书影音游列表导出另一份 CSV。

### 方式 B：使用现有开源导出工具

DoubanLens 的前端解析器内置了多格式智能字段映射，可直接拖入以下常见工具导出的文件：
- **Chrome 插件导出**：如 `douban-archive` 导出的 `.json` / `.csv`
- **桌面/CLI 工具导出**：如 `豆伴`、`douban-cli` 导出的 `.xlsx` / `.csv` / `.json`
- **多 Sheet Excel**：支持把电影、读书、游戏、音乐分 Sheet 存放的 `.xlsx` 文件，系统会根据 Sheet 名称自动识别品类。

### 方式 C：手动整理或脚本转换

如果你自己有历史备份，只需整理成下方的标准 8 列 CSV（或包含对应字段的 JSON / Excel）即可直接导入。

## 标准数据格式规范

推荐使用 **UTF-8（带 BOM）编码的 CSV**，标准表头共 8 列：

| 列名 | 是否必填 | 允许值 / 格式说明 | 用途 |
| :--- | :---: | :--- | :--- |
| `标题` | **必填** | 作品名称（支持豆瓣原生 `中文名 / 原名` 格式，界面会自动截取主标题） | 核心展示 |
| `分类` | 推荐 | `电影` / `读书` / `游戏` / `音乐`（若留空会自动从 `链接` 或 `状态` 推断） | 四维统计与筛选 |
| `状态` | 推荐 | `看过` / `在看` / `想看`、`读过` / `在读` / `想读`、`玩过` / `在玩` / `想玩`、`听过` / `想听` | 区分已完成与愿望单扭蛋池 |
| `评分` | 推荐 | `5星`~`1星` / `5`~`1` / `力荐`~`很差` / `未评分` 或留空 | 均分、星级分布、红黑墙、碰撞打分 |
| `标记日期` | 推荐 | `YYYY-MM-DD`（如 `2026-11-24`） | **热力图、时间线、扭蛋机积灰天数** |
| `标签` | 可选 | 空格或逗号分隔的个人标签 | 预留扩展 |
| `短评` | 可选 | 你的豆瓣短评文本（若含英文逗号或换行，请用英文双引号 `""` 包裹） | 时间线切片、红黑吐槽墙、双人 PK |
| `链接` | 强烈推荐 | 完整豆瓣条目 URL（如 `https://movie.douban.com/subject/1292226/`） | **双人口味碰撞按条目 ID 精确匹配** + 一键跳转豆瓣 |

**最小 CSV 示例：**

```csv
分类,状态,标题,评分,标记日期,标签,短评,链接
电影,看过,2001太空漫游 / 2001: A Space Odyssey,5星,2026-11-24,,服化道让人惊叹,https://movie.douban.com/subject/1292226/
读书,读过,置身事内：中国政府与经济发展,5星,2026-10-05,,财政逻辑讲透了,https://book.douban.com/subject/35546622/
游戏,在玩,领主 Suzerain,5星,2026-04-22,,硬核政治模拟器,https://www.douban.com/game/35196662/
音乐,听过,万能青年旅店,5星,2026-11-01,,小号一响鸡皮疙瘩起来了,https://music.douban.com/subject/5365226/
```

## AI 辅助总结使用方式

时间线、高低分对照、愿望单抽取、双人对比这 4 个页面均支持以下两种调用方式：

### 方式 1：无 API Key 复制粘贴模式

如果没有 API Key，可以直接使用任意网页版大模型：
1. 点击页面上的「复制 Prompt」，程序会将精简后的数据摘要与输出格式说明复制到剪贴板；
2. 粘贴发送给任意网页版对话模型（DeepSeek / ChatGPT / Claude / Gemini / Kimi 等）；
3. 将返回的 JSON 粘贴回页面输入框，点击解析即可在页面中展示。

### 方式 2：自带 API Key 直连（BYOK）

1. 点击顶部「配置 AI」；
2. 选择预设服务商（内置 DeepSeek / OpenAI / Gemini OpenAI 兼容 / OpenRouter / Kimi，也支持自定义兼容地址）并填写自己的 `API Key`；
3. 在对应模块点击生成，请求由浏览器直接发往模型接口。

## 静态部署（GitHub Pages / Vercel）

本项目是纯前端静态应用（`vite.config.ts` 已配置 `base: './'` 相对路径），不需要购买任何服务器。

### 部署到 GitHub Pages（推荐，仓库已自带工作流）

1. 将本项目推送到你的 GitHub 仓库（默认分支为 `main`）；
2. 打开仓库页面 → **Settings** → 左侧 **Pages**；
3. 在 **Build and deployment → Source** 中选择 **GitHub Actions**；
4. 仓库内置的 [.github/workflows/deploy.yml](./.github/workflows/deploy.yml) 会在每次 push 到 `main` 时自动打包并发布到 `https://<你的用户名>.github.io/<仓库名>/`。

### 部署到 Vercel

1. 登录 [Vercel](https://vercel.com/) → **Add New Project** → 导入你的 GitHub 仓库；
2. Framework Preset 保持 **Vite**，Build Command 为 `npm run build`，Output Directory 为 `dist`；
3. 点击 **Deploy**，约 30 秒即可获得 HTTPS 访问域名。

## 隐私与安全说明

- **数据不出浏览器**：你的 CSV / Excel / JSON 文件仅在本地浏览器内存中解析与计算，**不会上传到任何项目方服务器**（本项目本身没有后端）。
- **API Key 本地存储**：BYOK 模式下填写的 API Key 仅保存在当前浏览器的 `localStorage` 中，请求由浏览器直接发往你填写的模型服务商接口。
- **不会自动发请求**：只有在你主动点击 AI 生成按钮时，才会把压缩后的作品摘要发送给你配置的模型接口；使用纯本地功能全程零网络请求。

## 常见问题（FAQ）

**Q1：导入 CSV 后中文乱码怎么办？**
请确保 CSV 文件使用 **UTF-8**（或 UTF-8 with BOM）编码保存。如果是 Excel 导出的 ANSI/GBK 编码 CSV，建议直接上传原始 `.xlsx` 文件，或者在编辑器中另存为 UTF-8。

**Q2：如果我的记录里没有 `链接` 列，双人口味碰撞还能用吗？**
可以！系统优先使用豆瓣 `链接` 中的唯一 `subject ID`（如 `movie:1292226`、`game:35196662`）做精准匹配；如果没有链接，会自动回退到「分类 + 标准化主标题」匹配。

**Q3：为什么我点 BYOK 一键生成提示 CORS 跨域或 401 错误？**
- `401` 表示 API Key 无效或额度不足；
- 少数模型代理站点未开放浏览器端跨域（CORS）请求，此时可以更换支持浏览器直连的服务商（如 DeepSeek、OpenRouter、Gemini），或直接使用 **「免 Key 复制 Prompt」** 模式，不受任何跨域限制。

**Q4：导出的长图里为什么没有 AI 总结文字？**
长图是直接截取页面当前的卡片区域生成的。先在页面上完成一次 AI 总结（直连或复制粘贴 JSON 均可），待卡片更新后再点击导出 PNG 即可包含在内。
